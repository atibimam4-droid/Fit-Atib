# Fit-Atib
Fit Atib is a modern, responsive fitness web application featuring an advanced daily protein calculator, budget-friendly diet plans, and a comprehensive database of 35+ protein sources to help users achieve their fitness goals.
Fit Atib - Advanced Protein Calculator & Fitness Hub

Fit Atib is a premium, single-page fitness web application designed to help users calculate their exact daily protein requirements based on their body metrics and specific goals (Bulking, Cutting, or Maintaining). Built with HTML, Tailwind CSS, and Vanilla JavaScript, it features a sleek dark-themed UI with glassmorphism effects and smooth scroll animations.

Key Features:

Advanced Macro Calculator: Calculates daily protein needs based on age, gender, height, weight, and fitness goals.

Budget-Based Diet Plans: Provides practical food sources tailored to both low (economy) and high (premium) budgets in the local market.

Ultimate Protein Database: A comprehensive, interactive modal containing over 35 plant and animal-based protein sources with digestion details.

Fitness Articles: Built-in informative modals covering hypertrophy, consistency, and the science of recovery.

Fully Responsive: Optimized for both mobile and desktop screens.
